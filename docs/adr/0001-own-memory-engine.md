# Own transparent memory engine instead of calling mem0 directly

The book's example calls the mem0 library (`memory.add`, `memory.search`). Those calls hide the steps a learner needs to see: the candidate facts extraction produced, which existing memories were compared with each one, the short ids the model saw, the model's raw decisions, and the similarity scores. So tabs ① to ⑥ run on our own small engine (`memory_lab/pipeline.py`) that follows mem0 0.1.113's algorithm step by step and uses its prompts word for word (a test checks they are identical). It stores memories in a JSON file with cosine search, not Chroma. We accept that this is a teaching copy, not the library (no graph memory, no async, no metadata filters). To keep it honest, tab ⑦ runs the real `mem0ai==0.1.113` on the same data and models so the two can be compared.
